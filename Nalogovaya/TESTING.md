1. Цель тестирования

Проверить корректность работы основных функций приложения: авторизации, управления проектами, управления задачами и формирования PDF-отчётов.

2. Основные сценарии тестирования

Проверка входа с корректными учётными данными.

Проверка входа с неверным паролем.

Проверка добавления проекта.

Проверка редактирования проекта.

Проверка удаления проекта.

Проверка создания задачи.

Проверка редактирования задачи.

Проверка удаления задачи.

Проверка обновления списка задач.

Проверка формирования PDF-отчёта.

3. Проверка связи с базой данных

При выполнении операций приложение обращается к базе данных Nalogovaya, расположенной в SQL Server. Необходимо убедиться, что данные сохраняются и корректно отображаются после повторной загрузки.

4. Ожидаемый результат

Все операции выполняются без ошибок, изменения сохраняются в базе данных, а PDF-отчёт формируется в соответствии с выбранными данными.

5. Фиксация результатов

Для каждого сценария следует записать фактический результат и отметить, пройден ли тест. Непройденные тесты необходимо повторить после исправления ошибок.
