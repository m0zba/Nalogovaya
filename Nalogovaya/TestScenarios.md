# Тестовые сценарии приложения «Налоговая»

# Сценарий / Ожидаемый результат 

 # 1 Вход с правильным логином и паролем / Открывается главное окно 
 # 2 Вход с неправильным паролем / Появляется сообщение об ошибке 
 # 3 Добавление проекта / Проект появляется в списке 
 # 4 Редактирование проекта / Новые данные сохраняются 
 # 5 Удаление проекта без связанных задач / Проект удаляется 
 # 6 Создание задачи / Задача появляется в списке 
 # 7 Изменение статуса задачи / Новый статус сохраняется 
 # 8 Редактирование задачи / Изменения отображаются в списке 
 # 9 Удаление задачи / Задача исчезает из списка 
 # 10 Формирование PDF-отчёта / Создаётся PDF-файл с данными 

# Порядок выполнения

1. Подготовить необходимые тестовые данные.
2. Выполнить каждый сценарий вручную.
3. Сравнить фактический результат с ожидаемым.
4. Записать результат: «Пройден» или «Не пройден».
5. При обнаружении ошибки описать её и повторить тест после исправления.
